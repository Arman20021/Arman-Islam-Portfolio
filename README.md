# Arman Islam Portfolio

A modern, responsive personal portfolio website for showcasing my skills, projects, competitive programming profiles, achievements, and contact information.

## Live Website

Visit my portfolio here:

https://armanislam.netlify.app/

## About

This portfolio website represents my academic background, technical skills, development projects, and competitive programming journey. It is designed with a clean modern UI, smooth animations, responsive layout, and interactive sections.

## Features

* Modern responsive design
* Smooth scrolling and reveal animations
* Animated hero section
* Skills section with icons
* Competitive Programming profile section
* Project showcase cards
* Contact section
* Anonymous suggestion form using Formspree
* Custom favicon/logo
* Mobile-friendly navigation

## How to Run Locally

1. Clone the repository

git clone https://github.com/Arman20021/arman-islam-portfolio.git

2. Open the project folder

cd arman-islam-portfolio

3. Open `index.html` in your browser

Or use VS Code Live Server for better development experience.
